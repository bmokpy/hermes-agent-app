# Privacy Policy

Hermes Agent is a personal, self-hosted automation tool. This policy describes how
it handles data.

- **What data is accessed:** With the owner's explicit authorization via OAuth,
  the application accesses the owner's own Google account data (Gmail, Google
  Calendar, Google Drive) solely to perform tasks the owner requests.
- **Data storage:** Data is processed only to fulfill the owner's commands and is
  not sold, rented, or shared with any third party.
- **No analytics or tracking:** The application does not collect analytics or
  track users.
- **Data removal:** The owner can revoke access at any time from their Google
  Account settings (Security > Third-party access), which stops all data access
  immediately.
